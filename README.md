# Finance Dashboard – Full Stack Project

## Overview

This project is a full-stack finance dashboard application designed to manage financial records and user access in a structured way.

It is built using a microservices-based backend and a React frontend, with a focus on clean architecture, secure access, and real-world system design.

---

## Project Structure

The project is divided into two main parts:

### Backend
The backend follows a microservices architecture and includes:

- Auth Service – handles authentication and token generation  
- User Service – manages users and roles  
- Finance Service – manages financial data  
- API Gateway – routes all requests  
- Eureka Server – service discovery  

### Frontend
The frontend is built using React and provides a user interface for:

- Login and authentication  
- Managing users  
- Managing financial records  
- Viewing dashboard analytics  

---

## Key Features

- Role-based access control (Admin, Analyst, Viewer)  
- JWT-based authentication  
- Financial records management (CRUD operations)  
- Dashboard with summary insights  
- Microservices architecture with API Gateway  

---

## How It Works

1. User logs in through the frontend  
2. JWT token is generated by the Auth Service  
3. All requests go through the API Gateway  
4. Gateway routes requests to appropriate services  
5. Services interact with their respective databases  

---

## Tech Stack

- Backend: Java, Spring Boot, Spring Security, Spring Cloud  
- Frontend: React.js  
- Database: SQL Server
